# Estudo da Cris

- **Abrir o site:** duplo clique em `index.html` (abre no browser). Funciona sem internet, só a letra fica diferente.
- **O progresso** fica guardado neste browser, neste computador. Para ter uma cópia: botão "Exportar progresso" no fim da página inicial.
- **Se as fichas mudarem** (`documentos/leis/fichas_diarias/`): correr `node build/converter.js` dentro desta pasta. Gera de novo `data.js` (e `build/data.json`).
- O script para e mostra o erro se a conta não bater (37 fichas, 440 perguntas do Dia 2 ao 37, 16 no Dia 1).
- Ficheiros: `index.html`, `style.css`, `app.js` (o site) e `data.js` (as perguntas, gerado — não editar à mão).
